# NISA 配当ウォッチ

日経 225 の全銘柄と、自分で追加した銘柄の **配当・株価の指標** を一覧にする、Mac で動く Web アプリです。
NISA で高配当株を長く持つ前提で、「いまの利回りは過去と比べてどうか」「株価は高値圏か安値圏か」を見比べるために作りました。

> **投資助言ではありません。** 画面の「エントリー目安」は、下に書いた決まりで点数を付けただけの機械的な判定です。
> データは Yahoo Finance から取得しており、遅れや誤りを含むことがあります。売買の判断は、会社の公式情報を確認したうえでご自身で行ってください。

## できること

- **一覧**：株価、前日比、配当利回り（会社予想、なければ直近 12 か月の実績）、5 年平均利回り、配当性向、PER / PBR、52 週レンジの位置、RSI、移動平均からの乖離、1 年・3 年の騰落率、3 年リターン（配当込み）
- **絞り込み**：利回り（2% / 3% / 3.5% / 4% 以上）、配当月、エントリー目安
- **銘柄の詳細**：株価の推移（75 日・200 日移動平均つき）、年間配当の推移、権利確定月と受取月の目安、エントリー目安の根拠
- **NISA 試算**：投資額から、年間の配当と成長投資枠（年 240 万円）に占める割合を計算
- **銘柄の追加と削除**：4 桁の銘柄コード（`285A` のような新しい形式も可）や米国株のティッカーを追加できる
- **日経 225 の再同期**：Wikipedia の構成銘柄一覧から最新の 225 銘柄を取り込む（取り込めなかったときは同梱の `nikkei225.json` を使う）

## 必要なもの

- Python 3.9 以上
- ライブラリ：`flask`、`yfinance`、`pandas`、`requests`
- インターネット接続（Yahoo Finance と Wikipedia に接続する）

## 起動

```bash
git clone https://github.com/yubun241/nisa-dividend-watch.git
cd nisa-dividend-watch
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

ブラウザで <http://127.0.0.1:5057/> が自動で開きます。終了するときは、ターミナルで Ctrl+C を押します。

- 初回は 225 銘柄分のデータを取るため、30 秒〜1 分ほどかかります。
- 取得したデータは `cache.pkl` に保存され、次からはすぐ表示されます。30 分より古くなると、裏で自動的に取り直します。
- `--no-browser` を付けると、ブラウザを開かずに起動します。
- このアプリは自分の PC の中（`127.0.0.1`）だけで動き、外からは接続できません。

### Mac でダブルクリックで起動する

`NISA配当ウォッチ.command` をダブルクリックすると起動します。
中で作者の環境の venv（`/Users/luna/python/env1`）を指定しているので、ほかの環境で使うときは 4 行目を自分の venv の場所に書き換えてください。

## 指標の計算方法

| 指標 | 計算 |
|---|---|
| 配当（年間） | Yahoo の予想配当。予想が直近 12 か月の実績の 0.5〜2 倍から外れるときは、株式分割などで値がずれている可能性があるため実績を使い、警告を出す |
| 利回り | 年間配当 ÷ 株価 |
| 52 週の位置 | 52 週の安値を 0%、高値を 100% としたときの現在の株価の位置 |
| RSI | 14 日（指数平滑） |
| 連続非減配年数 | 暦年ごとの配当合計を比べ、前の年を下回らなかった年数 |
| 権利確定月・受取月 | 直近およそ 1 年の権利落ち日の月。受取月は目安で、日本株は約 3 か月後、ETF は約 1 か月後、海外株は約 2 週間後として計算 |
| 単元 | 日本株は 100 株、ETF と海外株は 1 株 |

### エントリー目安（点数の付け方）

| 条件 | 点数 |
|---|---|
| 利回りが 5 年平均の 1.15 倍以上 / 1.0 倍以上 / 0.8 倍以下 | +2 / +1 / −1 |
| 52 週の位置が 25% 以下 / 45% 以下 / 75% 以上 / 90% 以上 | +2 / +1 / −1 / −2 |
| RSI が 30 以下 / 40 以下 / 70 以上 | +2 / +1 / −2 |
| 200 日移動平均以下 / 20% 以上の上方乖離 | +1 / −1 |
| 配当性向が 100% 超 | −2 |
| 直近数年に減配あり | −1 |

合計 4 点以上で「買い場候補」、2 点以上で「押し目気味」、−2 点以下で「過熱気味・待ち」、それ以外は「中立」とします。

## データについて

- 株価と配当：[yfinance](https://github.com/ranaroussi/yfinance) を通して Yahoo Finance から取得。日本語の銘柄名は Yahoo!ファイナンス（日本）のページタイトルから取得しています。どちらも個人の利用を前提にしています。
- 日経 225 の構成銘柄：Wikipedia「[日経平均株価](https://ja.wikipedia.org/wiki/日経平均株価)」（CC BY-SA 4.0）の構成銘柄一覧を解析しています。
- Yahoo や Wikipedia のページの形式が変わると、取得できなくなることがあります。
